ASST BRIANZA - NO-CORE PULIZIE MOBILE
Proprietario: DR. INCORVAIA LUIGI

Questo progetto Android produce un APK installabile per Android 8 o superiore.

BUILD CON ANDROID STUDIO
- Aprire questa cartella in Android Studio.
- Attendere la sincronizzazione Gradle.
- Build > Build APK(s).

BUILD CON GITHUB ACTIONS
- Pubblicare il progetto in un repository GitHub.
- Aprire Actions > Build Android APK > Run workflow.
- Scaricare l'artefatto NO-CORE-Pulizie-APK.

SINCRONIZZAZIONE
- Sul PC usare la versione desktop Mobile Sync e avviare AVVIA_NO_CORE_CON_SYNC.exe.
- Nel programma PC premere "Sincronizza Telefono" e copiare indirizzo LAN e codice a 6 cifre.
- Nell'app Android aprire la scheda Sync, inserire indirizzo/codice e premere Sincronizza ora.
- PC e telefono devono essere sulla stessa rete Wi-Fi/LAN.
- Audit, problemi, agenda e referenti sono bidirezionali. Gli allegati non sono sincronizzati nella v1.
